# Changelog

## 1.0.0 - 2026-10-17
First public release.
- Swaps Skyrim VR's overlay keyboard for the standard SteamVR keyboard, which shows up on the Steam Frame.
- Rebuilds the typed text from the compact keyboard's single-key buffer (backspace and accented letters supported).
- Typed-text box above the keyboard, world-fixed or head-locked, configurable size and position.
- INI next to the DLL (read only), short log with an optional debug mode.
- Optional emergency hotkeys (Ctrl+Alt+K / Ctrl+Alt+H), off by default.
